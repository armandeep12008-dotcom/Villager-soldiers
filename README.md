# Villager Soldiers - add-on for Guard Villagers (Fabric, Minecraft 26.2, Java 25)

Requires the **Guard Villagers** mod (MIT, by MrSterner) and Fabric API in your mods folder.
All soldiers are real Guard Villagers guards: same AI, weapon handling, model/textures,
inventory screen and follow/patrol buttons. This mod only adds mounts, loadouts and spawn eggs.

Eggs (Spawn Eggs tab) or `/soldier spawn <type>`:
infantry_sword, infantry_spear, infantry_bow, infantry_crossbow, horse_sword, horse_spear,
camel_guards (2 guards), ghast_squad (4 archers on a happy ghast).

Guard Villagers is (c) MrSterner, MIT licence; libs/guardvillagers.jar is used for compilation only.
